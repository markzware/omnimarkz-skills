# Social image and caption

Make a social image and a caption from an InDesign, Publisher, QuarkXPress, or PDF file.

Connect OmniMarkz from **OmniMarkz → Preferences → MCP** before using this skill. OmniMarkz MCP is the local app you connect there. This repository does not give a remote URL for that MCP server.

The image and caption stay on the Mac. This skill does not post to a social network.

## Cursor

```bash
npx skills add markzware/omnimarkz-skills --skill design-file-social-image -g
```

## Claude

```text
/plugin marketplace add markzware/omnimarkz-skills
/plugin install omnimarkz@omnimarkz-skills
```

## Codex
