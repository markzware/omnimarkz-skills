# Changelog

Notable changes to the skills in this repository. Each skill has its own version number. A heading is the date that change landed on `main`.

## 2026-10-30

### Added

- **design-file-slides 1.** Turn an InDesign, Publisher, QuarkXPress, or PDF file into a PowerPoint in reading order. The deck stays on the Mac. This skill does not upload it.

## 2026-10-29

### Added

- **design-file-to-wordpress 4.** Turn an InDesign, Publisher, QuarkXPress, or PDF file into a WordPress draft, and use a Google font when one can stand in for a design font. The catalog `updated` date for this version is 2026-10-23. **Open tutorial** opens this folder through `https://markzware.com/notifications/omnimarkz-2026/skills/design-file-to-wordpress`.
- **design-file-what-changed 1.** Compare two versions of an InDesign, Publisher, QuarkXPress, or PDF file and report the text and photos that changed.
- **design-file-social-image 1.** Make a social image and a caption from an InDesign, Publisher, QuarkXPress, or PDF file. The image stays on the Mac. This skill does not post to a social network.

### Changed

- The repository README installs every skill with one Cursor command: `npx skills add markzware/omnimarkz-skills --skill '*' -g -y`.
